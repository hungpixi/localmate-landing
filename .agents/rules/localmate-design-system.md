# LocalMate Design System SSOT

## 1. Nguyên Tắc Cốt Lõi
1. **Light Theme Chủ Đạo**: Nền sáng (`#fbfcfb`, card surface `#ffffff`), chữ tối (`#17212b`, `#4b5563`). Nền tối thì chữ sáng (`#ffffff`).
2. **Tuyệt đối KHÔNG dùng Glassmorphism**: Không dùng blur mờ đục hoặc viền phản quang gây khó đọc.
3. **Đơn Giản, Thực Tế, Rõ Ràng**: Tối ưu trải nghiệm thực tế cho khách hàng doanh nghiệp địa phương / chủ cửa hàng.

## 2. Bảng Màu Thương Hiệu (Brand Palette)
- **Primary Brand Green**: `#0d7647` (Hover: `#0a5d37`, Active: `#074528`)
- **Accent Green**: `#16a34a` / `#22c55e`
- **Background Light**: `#fbfcfb`
- **Surface / Card**: `#ffffff`
- **Border**: `#e5e7eb` hoặc `#dcfce7` (viền xanh nhạt)
- **Text Primary**: `#111827` / `#17212b`
- **Text Muted**: `#4b5563` / `#6b7280`

## 3. Typography & Spacing
- **Font**: Inter / Be Vietnam Pro, hiển thị sắc nét trên mọi tỉ lệ zoom Windows 100% - 150%.
- **Section Padding**: `py-12 sm:py-16 px-4 sm:px-6`
- **Card Padding**: `p-5 sm:p-6 rounded-2xl`
- **Container Max-Width**: `max-w-6xl` hoặc `max-w-7xl`
